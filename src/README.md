Research Source Code

This folder contains the source code for the IEEE-CIS adaptive fraud detection research project.

Planned modules:

- Data preprocessing
- Chronological dataset splitting
- XGBoost model training
- Threshold optimization
- Temporal drift analysis
- Missingness analysis
- Model evaluation

Code will be added and tested as the reproducibility package is organized.

Important: The original Kaggle dataset and private credentials must not be uploaded here.
