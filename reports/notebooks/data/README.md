Research Dataset

This project uses the IEEE-CIS Fraud Detection dataset from Kaggle.

Dataset page:
https://www.kaggle.com/competitions/ieee-fraud-detection

The dataset must be downloaded separately by each researcher under Kaggle's applicable terms.

Important:

- Do not upload the original transaction or identity CSV files.
- Do not upload private or sensitive data.
- Keep raw datasets outside the public GitHub repository.

Expected input:

- "train_transaction.csv"
- "test_transaction.csv"

The "train_identity.csv" file was not merged in the current research analysis.
